Primary User

The primary user is an AI agent. Human readability matters only because agents and humans share the same terminal, logs, and repository. The runtime must optimize for fast agent decisions: bounded data, explicit next commands, stable reason codes, stale-state detection, and clear write boundaries.

Agent Contract

needsurfacegate
Can I act?inspect --target, check --jsonReport has status, reason, recommendation, commands, workflow, and evidence.
Is my view stale?report hash, full context hashDefault report carries a hash usable by apply --verify-report; full context hash remains explicit.
Why is it blocked?explain <target>Explanation names the config, policy, and fact edges that produced the report decision.
Is the tool usable here?doctorDoctor reports topology, config, target, bundle, and runner/release readiness without writing.
What should I run next?report.commands, report.workflowCommands are config-filtered suggestions and never auto-executed by report generation.

Design Rule

agent question
  -> bounded report or explanation
  -> explicit suggested command
  -> optional apply boundary
  -> evidence

Do not add features that require the agent to read a large dump first and infer intent from it. Full context is a support surface, not the product surface.
