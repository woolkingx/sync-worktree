Role

report is the AI-facing product data. Its job is to be short, precise, actionable, and bounded. It should tell the agent what happened, what is risky, what to do next, which commands are safe to run, and which workflow should follow.

Report Fields

fieldmeaningsource
statusCurrent runtime emits ready or blocked for pre-execution reports.checker/advisor transform
reasonStable short reason code for the status.checker/advisor transform
summaryOne short state summary the AI can quote or act on.advisor transform
risksBounded list of blocking or warning risks.checker transform
recommendationOne preferred next move.advisor transform using config.command_style
commandsSafe command suggestions, not auto-run.advisor transform using config.command_style
workflowStep-by-step next actions with rerun point.advisor transform
evidenceSmall proof set: source/target heads, dirty counts, action counts, policy ids.git/planner/checker transforms
full_tracenull by default; populated only when an explicit full trace mode is requested.reporter transform
metaOptional wrapper metadata such as report hash and generated timestamp.report wrapper transform

Context Budget

Default report output is compact and omits full file lists such as sync_files. Full traces are explicit: check --json --full and sync --json --full include trace data, while inspect --full returns the older full context contract.

Freshness

Agents need a cheap stale-state check. Default report wrappers should carry a deterministic report_hash over the report payload. apply may verify that hash before acting, while full context hash remains available for full-context workflows.

  "commands": [

  "workflow": [
    "review target dirtiness",
    "commit, stash, or ask the user according to config.command_style",
    "rerun sync-worktree check release"
  ],
  "evidence": {
    "target": "release",
    "source": "master@5742bc1",
    "dest": "/repo/release",
    "changes": {"A": 0, "M": 4, "D": 0, "P": 0},
    "policy_errors": 1,
    "policy_warnings": 0
  },
  "full_trace": null
}

This is the implemented report owner shape used by check --json, sync --json, inspect --target, and apply --dry-run.
