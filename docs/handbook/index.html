sync-worktree Handbook

sync-worktree is AI decision support for Git worktree operations. It is built to keep agents from making Git/worktree changes without a bounded report, clear recommendation, executable command suggestions, workflow guidance, and evidence. Syncing files is one executable decision; the core product is a compact config -> report -> decision -> apply loop.

Core Chain

config
  -> git facts
  -> transform submodules
  -> report
       status
       summary
       risks
       recommendation
       commands
       workflow
       evidence
  -> decision
  -> optional apply

The two persistent owners are config and report. Git readers, topology detection, planner, policy checks, advisor logic, and executor are submodules that transform data into or out of those owners. They do not own durable product truth.
