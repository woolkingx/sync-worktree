Non-Goals

  • Do not replace Git worktree semantics with generic rsync behavior.
  • Do not dump full repository context by default.
  • Do not create new durable data owners when a value is only transform state.
  • Do not make target worktrees editable sources of truth.
  • Do not add daemon behavior before CLI and contract boundaries are clear.
