Report Shape

{
  "status": "ready|blocked|warning|applied|failed",
  "reason": "target_dirty|policy_block|ready_to_apply|...",
  "summary": "short human-readable state",
  "risks": [],
  "recommendation": "one preferred next move",
  "commands": [],
  "workflow": [],
  "evidence": {},
  "full_trace": null
}

Report is bounded by config. If the report would grow past its budget, it must summarize and point to an explicit full trace mode.

Owner Rule

If a new durable field is user preference, policy, command style, budget, target, or role, it belongs to config. If it is AI-facing status, recommendation, command, workflow, risk, or evidence, it belongs to report. Everything else should stay a transform-local object unless there is a concrete durable data reason.
